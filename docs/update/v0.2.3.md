# v0.2.3

## 版本

`0.2.3`

## 发布时间

2026-10-03

## 概述

本版本是一次界面与交互改进版本，覆盖三部分：设置页的版本检查区域改为引导用户前往下载页并用小红点提示新版本；删除 AI 助手的确认流程由浏览器原生 `window.confirm` 换成应用内自绘弹窗；侧边栏在展开态直接展示账号信息，并把默认状态改为折叠。三个版本文件同步到 `0.2.3`，README 版本徽章同步更新。

## 新功能与变更

- 设置页“关于”区域新增“前往下载”按钮，点击后在系统浏览器打开下载页 `https://leetcode-note.benson.in.net/download`（`src/utils/releaseCheck.js` 新增 `DOWNLOAD_PAGE_URL`），替代原先直接跳转到 GitHub Releases 页的行为。
- 检测到新版本时，设置页左侧“关于”入口显示玫红色小红点，并附带屏幕阅读器可读的“发现新版本”文本，避免用户需要进入页面才能知道有更新。
- 删除 AI 助手改用应用内确认弹窗：新增 `assistantToDelete` / `deletingAssistant` 状态，以 `role="alertdialog"` 的模态弹窗替代 `window.confirm`，支持点击遮罩、取消按钮和 `Escape` 键关闭；删除过程中按钮禁用并显示加载图标，成功后自动关闭并刷新列表，失败则保留弹窗并提示错误。
- 侧边栏展开时，账号按钮改为整行布局并展示头像与用户名，未登录时显示“未登录”；折叠态保留圆形头像按钮。头像拆为独立容器并去掉外层描边，聚焦样式改用 `focus-visible` 环。
- 侧边栏折叠状态改为默认折叠：仅当 `localStorage` 中显式记录为展开（值为 `0`）时才保持展开，否则首次启动即为折叠。`src/i18n/locales/app.js` 补充“未登录”的英文文案。
- 助手列表移除首项旁的“默认”徽章，默认助手改由选中态与设置项高亮表达。

## 修复

- 同步 `package-lock.json` 中的项目版本，从 `0.1.0` 更新为与 `package.json` 一致的版本号。
- 发布流程补充 README 版本徽章契约：`.agents/skills/leetcode-note-release/SKILL.md` 明确每次发布都要同步 `README.md` 与 `README.en.md` 顶部徽章（此前徽章长期停留在首发版本），并在发布后核验徽章版本。

## 构建与发布说明

GitHub Actions 预期构建并发布以下桌面安装包：macOS Apple Silicon 与 Intel DMG、Windows x64 MSI 与 NSIS 安装程序，以及 Linux x64 AppImage、DEB 和 RPM。每个安装包都包含对应 target triple 的 Go sidecar。macOS app 使用 ad-hoc identity `-` 签名，不需要 Apple Developer 账号，但不会获得 Apple 公证；首次打开若被 Gatekeeper 拦截，可前往“系统设置 > 隐私与安全性”并选择“仍要打开”。构建状态以本版本对应的 Actions run 为准。
