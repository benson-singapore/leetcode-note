# v0.3.1

## 版本

`0.3.1`

## 发布时间

2026-11-16

## 概述

本版本将题目列表与详情中的题号统一为 LeetCode 公开题号（`lc_frontend_id`，缺失时回落 `lc_id`），搜索与排序也按公开题号处理；同时内嵌浏览器窗口改为按主窗口所在屏幕可用区自适应大小并居中，避免小屏幕上窗口超出可视区域。

## 新功能与变更

### 公开题号优先展示

- 后端 `DisplayProblem`、`DisplayProblemList`、`ActivityDayProblem` 及日报/复习单日查询新增 `lcFrontendId` 并透传（`451dfcb`）。
- 题库搜索改为按标题或公开题号匹配，排序优先使用 `lc_frontend_id`（`COALESCE(NULLIF(...))`），回落 `lc_id`（`451dfcb`）。
- 前端题目详情、题库列表、热力单日表、每日目标与看板统一优先显示 `lcFrontendId`，缺失时回落 `lcId`（`451dfcb`）。

### 内嵌浏览器窗口自适应

- 按主窗口所在屏幕工作区 90% 设置内嵌窗口大小，上限 1800x1100，取不到屏幕信息时默认 1600x1000（`a06a77d`）。
- 改为在屏幕可用区内居中显示，替代原来的相对主窗口右下偏移（`a06a77d`）。
- 附带 `cargo fmt` 格式化（emit、空行、托盘缩放换行，无行为变化）（`a06a77d`）。
