# v0.2.2

## 版本

`0.2.2`

## 发布时间

2026-10-01

## 概述

本版本是一次针对构建产物的紧急修复。此前 GitHub Actions 通过 `server/go.mod` 的 `go 1.24.0` 安装并编译 Go sidecar，而 Go 1.24 的 TLS ClientHello 指纹会被 LeetCode 前方的 Cloudflare 判定为爬虫并返回 `403`（`Just a moment...`），导致 Actions 打包出的应用虽然能正常登录、也能弹出验证窗口，却始终无法拉取账号资料与刷题统计。本版本将 CI 固定到已验证可通过的 Go `1.26.x`，并补充本地构建告警。

## 新功能与变更

- `scripts/build-sidecar.sh`：构建 sidecar 前检测本机 Go 版本，低于 1.25 时打印显式告警，说明该版本指纹会被 Cloudflare 拦截（HTTP 403）并建议升级，避免本地打包再次产出无法同步数据的安装包。

## 修复

- 修复 Actions 打包产物无法同步 LeetCode 数据的问题：CI 不再用 `go-version-file` 读取 `server/go.mod` 的 `go 1.24.0`，改为在 `.github/workflows/release.yml` 中显式固定 `go-version: "1.26.x"`。原因是 Go 1.25 起 TLS ClientHello 指纹发生变化，可正常通过 Cloudflare；Go 1.24 及更早则被拦截并返回 `403`。

## 构建与发布说明

GitHub Actions 预期构建并发布以下桌面安装包：macOS Apple Silicon 与 Intel DMG、Windows x64 MSI 与 NSIS 安装程序，以及 Linux x64 AppImage、DEB 和 RPM。每个安装包都包含对应 target triple 的 Go sidecar，且本次由 Go 1.26.x 编译。macOS app 使用 ad-hoc identity `-` 签名，不需要 Apple Developer 账号，但不会获得 Apple 公证；首次打开若被 Gatekeeper 拦截，可前往“系统设置 > 隐私与安全性”并选择“仍要打开”。构建状态以本版本对应的 Actions run 为准。
