# v0.1.0

## 版本

`0.1.0`（首个版本）

## 发布时间

2026-09-30

## 概述

LeetCode Note 首次发布，提供以题目笔记、刷题复习和训练记录为核心的桌面应用，并集成 LeetCode 账号、AI 助手及内嵌题目浏览体验。

## 新功能与变更

- 新增 Tauri 桌面应用、React 界面和 Go 本地服务，并提供 LeetCode 题目笔记抽屉用户脚本。
- 提供题库、题目详情、数据看板、日历统计和复习模式；支持按题号排序、分页设置、通过率显示、随机复习题数及今日复习统计。
- 支持 LeetCode 账号登录、国内站/国际站选择、账号资料与刷题统计导入。
- 新增 AI 助手多实例配置、模型发现、默认模型链与故障切换，并支持 AI 优化笔记内容。
- 支持多种解题方案、代码演示、Markdown GFM 表格和内嵌 LeetCode 浏览器；浏览器可注入笔记与打卡入口。
- 新增训练打卡记录，支持进度状态、手感评分、代码快照，以及查看、编辑和复制记录内容。
- 新增中英文界面切换、应用官网预览站点及按路由更新的 SEO 元信息。

## 修复

- 修正题库与复习模式切换时组件状态相互影响的问题，以及题目状态统计口径和总数来源。
- 修正接口错误提示解析、代码编辑器初始化与状态管理、题目详情抽屉层级显示问题。
- 修复 AI 任务启动/停止时的锁死问题、导入已刷题目后未进入复习队列的问题，以及内嵌插件在 SPA 页面中未自动挂载的问题。
- 修正官网构建产物的基础路径。

## 构建与发布说明

GitHub Actions 预期构建并发布以下桌面安装包：macOS Apple Silicon 与 Intel DMG、Windows x64 MSI/NSIS 安装程序，以及 Linux x64 AppImage、DEB 和 RPM。macOS app 使用 ad-hoc identity `-` 签名，不需要 Apple Developer 账号，但不会获得 Apple 公证。首次打开若被 Gatekeeper 拦截，可前往“系统设置 > 隐私与安全性”并选择“仍要打开”。构建状态以本版本对应的 Actions run 为准。
