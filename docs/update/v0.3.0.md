# v0.3.0

## 版本

`0.3.0`

## 发布时间

2026-10-20

## 概述

本版本加入「今日目标」练习计划，把每日选题、完成进度与训练打卡串成一条可执行的练习路径；同时提供可开关的外部 HTTP API，并补充 Swagger 与日历单日详情接口，方便脚本和其他客户端读取题目、笔记与复习数据。训练记录现在会随笔记、代码和掌握程度自动落盘，首次练习也会生成对应记录。

此外，本版本新增按题号替换今日目标、列表手感与打卡状态展示，改进 AI 核心笔记生成、相似题目打开方式、HTML 演示全屏预览与 CLI 流式输出，并修复了打卡记录编辑、题库统计和 Codex CLI Node 版本选择等问题。

## 新功能与变更

### 今日目标

- 新增每日目标数据表、迁移、模型、仓储与服务，支持按日期查询、创建、清空和 AI 选题（`d4a2839`）。
- 新增今日目标页面与侧边栏入口，可配置题量、知识点和难度，展示完成进度；题目抽屉支持从目标页直接打开题目（`d4a2839`）。
- 今日目标列表新增「手感」与「打卡状态」列，移除知识点标签列，并在保存后同步本地手感（`7fd191d`）。
- 按题号添加题目时改为替换当天已有目标，并在 AI 重新生成、题号替换后给出对应提示（`82a424a`）。
- 跨天时自动刷新当前日期并重新加载目标，页面重新获得焦点时同步日期，避免继续显示前一天数据（`8e66a0f`）。

### 外部 API 与文档

- 新增可开关的外部 HTTP API 服务，使用 Bearer 令牌校验并支持独立端口；设置页可查看运行状态、访问地址、Swagger 入口和令牌（`c71ab57`）。
- 新增 Swagger 文档生成命令与后台 Swagger UI，提供 `/swagger/doc.json`（`c42963c`）。
- 新增 `/api/v1/calendar/day`，按本地自然日返回当日新建题目、复习打卡与每日目标的完整题目和答题数据（`41ff6e3`）。
- 新增 `docs/external/README.md`，并重新生成 Swagger，补充日历与每日目标接口及 `date` 查询参数说明（`1809c85`）。

### 训练记录

- 保存笔记、代码、掌握程度或手感时，将训练记录同步到最近一条打卡；尚无打卡时自动补建（`01144a3`）。
- 首次产生练习痕迹时自动生成「首次练习自动记录」；读取每日目标时兼容旧数据并补齐缺失记录（`01144a3`）。
- 题目详情接口返回最近一条打卡内容，笔记或代码保存后自动刷新详情；油猴脚本新增训练记录输入框（`01144a3`）。

### 学习与演示体验

- AI 解析核心笔记前可填写补充要求，并将要求与题目、代码和已有笔记整合生成（`1c12e58`）。
- 题目详情中的相似题目改为在应用内嵌浏览器打开，不再跳转外部新标签页（`606264c`）。
- HTML 演示改为应用内全屏预览，支持点击遮罩、关闭按钮和 Esc 关闭；演示内容异步到达时自动进入预览（`defba43`）。
- Claude CLI 启用 partial messages 实时输出增量文本，演示生成过程改为滚动文本域展示并显示已接收字符数（`bf0e76e`）。

## 修复

- 打卡记录编辑保存后同步更新列表并关闭编辑面板；时间显示统一优先使用 `created_at`，避免日期字符串被当作 UTC 时间解析（`2334f3f`）。
- 题库统计改为直接按 `progress_status` 表达式分组，避免使用别名导致统计口径异常（`a44187c`）。
- Codex CLI 按语义版本号选择最新的 nvm Node 版本，避免旧版本排在前面导致调用失败（`1cb8226`）。
- 补齐 v0.2.6 更新日志结尾换行，使其与 Release 正文一致（`4accd23`）。

## 构建与发布说明

推送 `v0.3.0` tag 后，GitHub Actions 预期构建并发布以下桌面安装包：macOS Apple Silicon 与 Intel DMG、Windows x64 MSI 与 NSIS 安装程序，以及 Linux x64 AppImage、DEB 和 RPM。每个安装包都包含对应 target triple 的 Go sidecar。

macOS app 使用 ad-hoc identity `-` 签名，不需要 Apple Developer 账号，但不会获得 Apple 公证；首次打开若被 Gatekeeper 拦截，可前往「系统设置 > 隐私与安全性」并选择「仍要打开」。构建状态以本版本对应的 Actions run 为准，本日志编写时尚未开始构建，不表示构建已成功。
