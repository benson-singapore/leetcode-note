# v0.2.5

## 版本

`0.2.5`

## 发布时间

2026-10-05

## 概述

本版本的主要变化是系统托盘交互的重做。原先托盘左键点击只是把主窗口唤出来，右键菜单里只有“显示窗口”和“退出”两项；本版本改为左键点击直接弹出一个常驻在托盘图标上方的学习概览浮窗，无需先唤起主窗口就能看到账号状态、LeetCode 刷题统计、本地题库进度和复习、日历等快捷入口。浮窗在 macOS 上启用了毛玻璃透明效果并重排为紧凑单栏布局，同时把概览数据的读取路径改为经由受限的 Rust 本地 API 通道转发，规避了 Tauri 弹窗直接发起 WebView 请求时容易出现的 “Load failed”。此外统一了账号头像的展示组件，并为托盘换上了新的 logo 图标。

## 新功能与变更

- 托盘左键点击弹出学习概览浮窗（`c235b2f`）：
  - 新增 `tray-popover` 无边框、置顶、不入任务栏的浮窗窗口，加载 `index.html?tray=1` 渲染独立界面；原先的托盘右键菜单（“显示窗口”/“退出”）被移除。
  - 浮窗按托盘图标位置定位显示，坐标会按主显示器范围做钳制，浮窗失去焦点时自动隐藏；浮窗已可见时再次点击托盘图标则直接隐藏。
  - 新增 `open_main_window` 与 `quit_app` 两个 Tauri 命令。`open_main_window` 先隐藏浮窗、唤起并聚焦主窗口，再向主窗口 emit `tray-navigate` 事件完成路由跳转；跳转目标限制在 `/`、`/problems`、`/problems/review`、`/calendar`、`/settings` 五个白名单页面内。
  - 新增 `src/TrayPopover.jsx`，展示账号信息、LeetCode 刷题统计、本地题库进度与快捷入口。
  - `src/main.jsx` 依据 `tray=1` 查询参数切换到浮窗组件，`src/App.jsx` 监听 `tray-navigate` 事件执行路由跳转。
- 托盘浮窗启用 macOS 毛玻璃透明效果（`4c5dd27`）：`Cargo.toml` 引入 `window-vibrancy` 并开启 Tauri 的 `macos-private-api` 特性，`tauri.conf.json` 同步设置 `macOSPrivateApi`。浮窗改为 `transparent(true)` 并应用 `Popover` 材质的毛玻璃，高度收敛为常量 `TRAY_POPOVER_HEIGHT`（460）；`src/index.css` 增加 `html.tray-popover` 的透明背景规则，`main.jsx` 在浮窗模式下为根节点添加该类名。
- 概览浮窗改为紧凑毛玻璃单栏布局（`207af60`）：移除卡片外层阴影容器，改为圆角透明单栏，各区块以半透明白色分隔线衔接毛玻璃背景；难度常量精简为只保留 key 与文案，进度条内联渲染并统一为天蓝色系；题库进度与刷题统计改为紧凑行式排版；引入 `localStatsAvailable` / `heatmapAvailable` 区分“加载中”与“数据不可用”，并补充加载、失败与未绑定账号的状态文案；快捷入口精简为题库、复习、日历三项。
- 新增 `UserAvatar` 组件统一头像展示（`b1a8894`）：`src/components/UserAvatar.jsx` 在头像加载失败时以名称首字母色块兜底。侧边栏账号卡片与折叠态入口改用该组件，账号存在但无头像时同样展示占位；设置页 LeetCode 账号入口改用该组件，未绑定 Cookie 时仍显示默认用户图标。
- 更换托盘图标为新 logo（`661708c`）：`tauri.conf.json` 的 `trayIcon.iconPath` 由 `icons/32x32.png` 改为 `icons/head-logo.png`，并在 `docs/logo/head-logo.png` 保留同名源图。

## 修复

- 概览数据改走受限的 Rust 本地 API 通道（`3d088b7`）：macOS 上的 Tauri 弹窗直接对本地 sidecar 发起 WebView 请求时，会以笼统的 “Load failed” 失败。此次抽出 `forward_sidecar_request` 复用侧车请求逻辑，新增 `tray_overview_api_request` 命令，仅放行 `/api/v1/settings`、`/api/v1/user-problems/stats`、`/api/v1/reviews/activity-heatmap`、`/api/v1/leetcode/user-profile`、`/api/v1/leetcode/solved-stats` 五个只读路径，并拒绝包含控制字符或空白字符的路径。`src/api/client.js` 新增 `getTrayOverview`，Tauri 环境下经 Rust 转发、浏览器开发模式仍走 HTTP；浮窗在登录信息、题库统计、活跃天数读取失败时给出具体提示。
- 修正高分屏下浮窗的定位偏移（`4c5dd27`）：托盘定位改用 `to_physical` 按缩放因子换算托盘图标矩形，不再直接对逻辑坐标做缩放乘法。
- 补充托盘浮窗在加载中、数据不可用与未绑定账号时的状态文案（`207af60`），避免空数据被误读为“已加载为零”。
- 笔记 AI 按钮文案由“AI 优化”改为“AI解析”（`31048fc`），更贴合点击后的解析行为。

## 构建与发布说明

GitHub Actions 预期构建并发布以下桌面安装包：macOS Apple Silicon 与 Intel DMG、Windows x64 MSI 与 NSIS 安装程序，以及 Linux x64 AppImage、DEB 和 RPM。每个安装包都包含对应 target triple 的 Go sidecar。macOS app 使用 ad-hoc identity `-` 签名，不需要 Apple Developer 账号，但不会获得 Apple 公证；首次打开若被 Gatekeeper 拦截，可前往“系统设置 > 隐私与安全性”并选择“仍要打开”。构建状态以本版本对应的 Actions run 为准。
